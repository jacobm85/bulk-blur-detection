# Models

`face_detection_yunet_2023mar.onnx` is the YuNet face detector from the
[OpenCV Model Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet), used by
`scoring.py` to find faces and eyes. It needs OpenCV 4.8 or later.
